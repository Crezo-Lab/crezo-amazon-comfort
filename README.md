# Crezo - Amazon Comfort & Infinite Scroll (v1.0.2)

Amazon.co.jp での検索体験を快適にする Chrome 拡張機能です。
怪しいマーケットプレイスや転売業者をワンクリックで除外し、自動スクロール（次ページのインライン追加）を提供します。

## 主な機能
- **🛡️ Amazon公式販売のみ絞り込み**: `&emi=AN1VRQENFRJN5` による正規品のみの一発絞り込み。
- **⚡ 自動無限スクロール**: 検索結果の最下部に到達すると次ページを自動取得。

## インストール方法
1. `chrome://extensions` を開く。
2. 「デベロッパーモード」をONにする。
3. 「パッケージ化されていない拡張機能を読み込む」から本フォルダを選択。

## 1.0.2 で直したこと
- 公式販売のみ: Amazon 以外の出品者が混ざる絞り込みでもオンと表示されていたのを直し、ほかの出品者の絞り込みが残ったままオンにすると0件になることがあったのを直しました。
- 自動スクロール: 並べ替え・絞り込みのあとに前の検索の続きが足される・同じ商品を取り続ける・次のページの商品が落ちる・失敗の直後にすぐ取り直す、を直しました。
- 拡張を更新したあと、前から開いていた Amazon のタブでスイッチが効かなかったのを直しました。
- ポップアップの見た目を整え（明るい画面・暗い画面の両方・行のどこでも押せる）、ブラウザが英語なら英語で出るようにしました。Amazon のページに出る文言も同じです。
- 使っていない権限を外しました。

## 1.0.1 で直したこと
- 自動スクロール: 「次へ」だけをたどる（最後のページで前のページを取り直さない）・同じ商品（data-asin）を二度足さない・新しい商品をページ送りの前に入れ、ページ送りを最新に差し替える・遅れて読む画像の data 属性から src を入れる・一覧の末尾の位置で読み込みを判定する。
- 読み込みに2回続けて失敗したとき、またはロボット確認の画面などで商品が0件のときは止めて「下のページ送りから進んでください」と出す（Amazon に取りに行き続けない）。
- Amazon公式販売のみ: 外すときに rh の中の Amazon 本体の出品者だけを外す（自分で選んだほかの出品者の絞り込みは残す・先頭のカンマが残る不具合も直した）。amazon.com では米国の出品者ID（ATVPDKIKX0DER）を使う。ポップアップのスイッチが今見ているタブに効くようにした。
- 開発支援（アソシエイトのタグ付け）を外した。Amazon アソシエイトの規約が拡張機能でのリンク利用を禁じているため。保存済みの設定も消す。
